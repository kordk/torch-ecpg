# AGENTS.md

Guidance for AI coding agents (Copilot, Claude, Cursor, Codex, etc.) working in
this repository. Human contributors are welcome to follow it too.

## Project at a glance

- **What it is:** Torch-eCpG (`tecpg`) is a GPU-enabled eQTM mapper that uses
  PyTorch to identify expression-associated CpG (eCpG) loci. It is a Python
  CLI / library, not a layered application.
- **Citation:** Kober, K.M., Berger, L., Roy, R. et al. *Torch-eCpG: a fast and
  scalable eQTM mapper for thousands of molecular phenotypes with graphical
  processing units.* BMC Bioinformatics 25, 71 (2024).
  https://doi.org/10.1186/s12859-024-05670-4
- **Entry point:** `tecpg` console script, defined in `setup.py` and rooted at
  `tecpg/cli.py`.
- **Layout:** Source under `tecpg/`; helper scripts under `tools/` and
  `pipeline*.sh` at the repo root; the `pytest` suite under `tests/`, with
  example/integration material under `demo/` and `docker-related/`.

## Install, build, run

```bash
# editable install for development
pip install --editable .

# CLI help
tecpg --help
```

`tecpg` automatically uses CUDA when available; pass `--threads N` (N > 0) to
force CPU. See `README.md` for full input-format and demo instructions.

There is no configured linter, formatter, or type checker in this repository.
Do not introduce one as part of an unrelated change. CI is limited to
`.github/workflows/tests.yml`, which runs `pytest tests/` on pull requests and
on pushes to `dev` (plus CodeQL and security scans). If you add or modify code,
run the relevant `tests/test_*.py` script(s) and any demo invocations affected
by your change.

## Project-specific overrides

The vendored rules are general-purpose. Where they conflict with the realities
of this codebase, the rules below win.

### Scientific / numerical code

- **Preserve numerical behavior.** Do not rewrite tensor expressions, einsums,
  broadcasting, or matrix algebra "for readability" if the rewrite changes
  shapes, dtypes, device placement, or floating-point results. If a rewrite is
  truly equivalent, verify against an existing `test_*.py` script before and
  after.
- **Variable names may match paper notation.** Short names like `M`, `G`,
  `C`, `X`, `y`, `n`, `df` are intentional and mirror the BMC Bioinformatics
  paper and standard statistics/regression notation. Do not rename them to
  long descriptive identifiers.
- **PyTorch idioms over generic refactors.** Prefer vectorized tensor
  operations over Python loops; keep `.to(device)` / `.cpu()` boundaries
  explicit; do not introduce abstractions that hide device or dtype.
- **Single-file modules are fine.** The flat `tecpg/` layout is intentional.
  Do not introduce package subdirectories, dependency-injection layers, or
  domain-driven structure for this CLI.

### Side effects to be aware of

- `tecpg`'s regression entry points call `helper.initialize_dir()` on the
  user-supplied `--output-dir`, which performs `shutil.rmtree()` followed by
  `os.mkdir()` — anything in that directory will be wiped. See
  `tecpg/helper.py`, `tecpg/processing.py`, `tecpg/regression_full.py`,
  `tecpg/regression_single.py`, `tecpg/import_data.py`. Preserve this contract
  unless the task is explicitly to change it, and do not point the option at a
  directory whose contents you need to keep.

### Dependencies

- New runtime dependencies require justification. The current set in
  `requirements.txt` / `setup.py` is small on purpose. Prefer NumPy / pandas /
  PyTorch primitives that are already available.

### Tests and data

- Do not commit large data files, model checkpoints, or anything generated by
  a `tecpg` run. The `demo/` and `tests/` directories contain only the small
  fixtures already checked in.
- When you change behavior, update or add the most relevant `test_*.py`
  script. Keep tests deterministic and runnable on CPU.

## Scope discipline

- Make the smallest change that solves the task. Do not opportunistically
  reformat, rename, or restructure unrelated code.
- If you find a real bug adjacent to your change, fix it and call it out;
  otherwise leave it alone.
